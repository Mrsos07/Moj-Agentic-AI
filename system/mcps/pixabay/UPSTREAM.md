# Upstream

Tool surface ported to Python from **Unlock-MCP/pixabay-mcp-server**
(https://github.com/Unlock-MCP/pixabay-mcp-server), MIT License.

Same tools and parameters: `search_images`, `search_videos`, `get_image_by_id`, `get_video_by_id`.
Reimplemented in-process (no Node runtime) against the public Pixabay API
(https://pixabay.com/api/docs/). Results are cached 24 h as the Pixabay API terms require.
