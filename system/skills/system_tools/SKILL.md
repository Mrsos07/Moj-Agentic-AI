# system_tools

مهارة **موظف** مدمجة وتعمل **دائماً** (`always_on`) — لا تحتاج تثبيتاً لكل موظف.

## ماذا تفعل

1. **الاكتشاف** في كل دورة: خوادم النظام المفعّلة التي نطاقها «الموظفين» + أدوات الموظف الخاصة.
   خادم فصله المالك من بطاقة الموظف لا يُستخدم (`business_rules.tools_opt_out`).
2. **التصنيف التلقائي** لكل أداة من اسمها ووصفها ومخطط وسائطها:
   - `search` — بحث بنص (مثل `tavily_search`)
   - `extract` — قراءة رابط (مثل `tavily_extract`)
   - `news` — أخبار
   أدوات الكتابة (delete / post / send / write…) لا يستدعيها الموظف أبداً.
3. **الإعلام**: سطر في تعليمات الموظف بالأدوات المتاحة، ورسالة للمالك عند تغيّرها.
4. **الاستدعاء عند الكتابة** (`app/aeos/employee/tool_use.py`):
   - منشور / ثريد: بحث بموضوع المنشور.
   - اقتباس: بحث بنص التغريدة + قراءة رابطها الخارجي إن وُجد (`research_before_quotes`، مفعّل).
   - رد: بنفس الطريقة إن فعّله المالك (`research_before_replies`، معطّل افتراضياً لتوفير الرصيد).

## الحدود

- الاستعلام نص الموضوع، والرابط من مادته — لا يختار محتوى X أداةً ولا وسائطها.
- النتائج تُحاط بـ `<<< >>>` مع تعليمات تجاهل أي أوامر داخلها.
- ذاكرة مؤقتة 6 ساعات للاستعلام نفسه، وخادمان كحد أقصى لكل نوع، ولا يتكرر بحث Tavily
  إن كان البحث المدمج يعمل بـ Tavily أصلاً.
