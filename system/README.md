# system/ — المجلد الرئيسي لقدرات النظام

## مستويان للقدرات

| | **قدرات النظام** (هذا المجلد) | **قدرات الموظف** (فرعية، خاصة به) |
|---|---|---|
| من يضيفها | المطوّر — لوحة التحكم `/admin` | مالك الموظف — بطاقة الموظف (الأدوات / المهارات) |
| لمن | مدمجة في النظام: منسّق كل مالك + الموظفون المسموح لهم | ذلك الموظف وحده — لا يراها مالك آخر ولا موظف آخر |
| MCP | إعداد JSON (stdio/HTTP) أو حزمة `.py`/`.zip` | **خادم HTTP عام فقط** (لا stdio ولا حزم ولا عناوين داخلية) |
| المهارات | `SKILL.md` للمنسّق + مهارات الموظفين البرمجية | مهارة مخصّصة بلغة المالك («كل صباح علّق على…») أو ملف |
| التخزين | `system/` (+ الأسرار في `data/`) | `data/employee_mcps/<id>.json` و`business_rules.custom_skills` — تُحذف مع الموظف |

لماذا HTTP فقط لأدوات الموظف؟ stdio والحزم **تشغّل أمراً أو كوداً على هذا الجهاز**، والتسجيل
مفتوح لأي مستخدم. والعناوين الداخلية مرفوضة (تُفحص بعد تحليل DNS وعند كل استدعاء، ولا تُتبع
التحويلات) حتى لا يصل مستخدم عبر خادمنا إلى X Suite أو loginx أو شبكته المحلية. خادم داخلي
يحتاجه الموظفون يثبّته المطوّر كأداة نظام ويتيحه لهم.

---

**كل** خوادم MCP وكل المهارات في النظام هنا — لا مكان آخر يُسجَّل فيه خادم أو مهارة.
تُحمَّل عند الإقلاع، ومنسّق **كل مالك** يتصل بها تلقائياً حسب نطاقها. يضيفها أو يعدّلها
أو يحذفها **المطوّر** وحده من لوحة التحكم (`/admin`).

```
system/
├── mcps/                          كل خوادم MCP
│   ├── x/  playwright_x/  content/  memory/      مدمجة أصلية (كود داخل العملية)
│   ├── browser/  news/  search/  image/
│   │   ├── mcp.json               kind: builtin · class · scope · coordinator_tools
│   │   └── server.py              الكود — المصدر الوحيد للخادم
│   └── <slug>/                    مرفوع من اللوحة (إعداد JSON أو حزمة .py/.zip)
│       ├── mcp.json               الإعداد (أسماء مفاتيح الأسرار فقط)
│       └── server.py …            كود الحزمة إن رُفعت كحزمة
└── skills/                        كل المهارات
    ├── team-weekly-report/ …      kind: coordinator — تعليمات SKILL.md للمنسّق العام
    └── on_this_day/ …             kind: employee — مهارة موظف: SKILL.md (الوصف) + skill.py (الكود)
```

## الخوادم: مدمج أصلي ومدمج مرفوع

بعد الرفع لا فرق في المكانة: الخادم المرفوع **مدمج** في النظام مثل الأصلي — في القائمة
نفسها، يُحمَّل عند الإقلاع، ويتصل به منسّق كل مالك. الفرق تقني فقط:

| | أصلي (`kind: builtin`) | مرفوع |
|---|---|---|
| التشغيل | داخل عملية الخادم (Python) | عملية منفصلة (stdio) أو HTTP عبر بروتوكول MCP |
| التعديل | في الكود (`server.py`) | من اللوحة (تفعيل، نطاق، أدوات، أسرار، حذف) |

**ما يصل إليه المنسّق مباشرة** (`scope.coordinator`): كل الخوادم **إلا**
- `x` — النشر والتفاعل على X: يبقى عبر الموظف (شخصيته، حارسه، ميزانياته).
- `memory` — ذاكرة الموظفين: أدواتها بمعرّف موظف؛ للمنسّق ذاكرته المعزولة.

قراءة X (`playwright_x`) متاحة للمنسّق **بحسابات مالكه فقط** (وسيط `account`)، ولا استثناء
حتى للمسؤول أو المطوّر.

## المهارات

| النوع | ما هي | من يستخدمها | يُرفع من اللوحة؟ |
|---|---|---|---|
| `coordinator` | تعليمات SKILL.md (معيار Agent Skills) | منسّق كل مالك: يرى الاسم والوصف، ويحمّل التعليمات بـ `use_system_skill` | نعم |
| `employee` | كود `skill.py` يقترح به الموظف أفعاله في كل دورة | الموظفون الأذكياء | لا — جزء من كود النظام |

`order` في SKILL.md لمهارات الموظفين مهم: المهارات تحجز أهدافها من حوض واحد، فالأفعال
النادرة عالية القيمة (اقتباس) تحجز قبل الوفيرة (إعجاب).

المساعدات المشتركة بين مهارات الموظفين في `app/aeos/skills/builtin.py` وتُستدعى بـ `_h.`.
المسارات القديمة (`app/aeos/mcp/servers/x_mcp.py`، `builtin.OnThisDaySkill`…) أسماء بديلة
تشير إلى الكود هنا نفسه.

## الأسرار

قيم `env`/`headers` للخوادم المرفوعة في `data/system_mcp_secrets.json`، وحالة التفعيل في
`data/system_state.json` — مجلد `data/` خارج git. لا تضع مفتاحاً في `mcp.json`.

## صيغة ملف إعداد MCP المرفوع

```json
{
  "mcpServers": {
    "weather": { "command": "npx", "args": ["-y", "@example/weather-mcp"], "env": {"API_KEY": "…"} },
    "docs":    { "type": "http", "url": "https://example.com/mcp", "headers": {"Authorization": "Bearer …"} }
  }
}
```

حزمة خادم: `server.py` واحد، أو `.zip` فيه `server.py` (أو `mcp.json` يحدّد `entry`).
تُشغَّل بمفسّر Python الخاص بالمشروع، ومجلد عملها مجلد الحزمة نفسه. اسم خادم مدمج أصلي
(`x`، `search`…) لا يُقبل لخادم مرفوع.
